# Tic-Tac-Toe

A clean, responsive two-player Tic-Tac-Toe game built with **HTML, CSS, and JavaScript**.

## Features

- Two-player O/X gameplay
- Automatic winner detection
- Draw detection
- Reset and New Game controls
- Responsive layout for desktop and mobile
- Accessible buttons and live game status
- No external dependencies

## Run locally

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/Bot-Aman/TIC-TAC-TOE_JS.git
cd TIC-TAC-TOE_JS
```

Then open `index.html` directly, or serve the folder with any static web server.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
